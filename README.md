`SKILL.md` is generated verbatim from the same source as the ChatGPT/Codex remote
plugin. `SOURCE.json` records source commit/path/hash; it is engineering metadata,

OAuth resource/client/profile and verified host registration. A Skill text file
alone cannot connect a tool. Keep these values out of public examples until they
are real; never use an old read-only endpoint as a new purchasing interface.

commerce policy and natural acceptance requirements. Run local content checks
